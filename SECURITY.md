# Security policy

Please report potential vulnerabilities privately through this repository's
GitHub Security Advisories reporting flow. Do not open a public issue for a
vulnerability before maintainers have had an opportunity to assess it.

Do not include credentials, access tokens, private keys, personal data, customer
data, or runtime logs in an advisory or issue. Provide the smallest reproducible
example possible and redact sensitive values.

Some provider integration fixtures may contain staging origins or public-key
configuration. Those are public configuration values, not secrets; they must not
be treated as authorization to access an environment. Reports must not include
credentials or attempt access beyond a reporter's own authorized environment.

This candidate repository does not make a response-time or release commitment.
