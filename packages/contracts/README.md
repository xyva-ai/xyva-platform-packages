# @xyva/contracts

Public, versioned and transport-safe contracts shared by XYVA products.

## Provider contracts V1

`@xyva/contracts/providers/v1` contains the canonical five-provider catalog,
capability negotiation, validated credential-free model discovery and
inference, cancellation, normalized usage and bounded failure contracts. The
same request and outcome types are used by QA Studio and Flow. It does not
contain API keys, tokens, endpoints, headers, sessions or provider-specific raw
responses.
